# Computer Science Course Projects

本仓库包含本人在课程学习与编程实践中完成的项目，涵盖 C++ 桌面应用、Java Web 开发、Python Web 应用和 Python GUI 程序。

## 项目总览

| 项目 | 技术栈 | 简介 |
| --- | --- | --- |
| [航空客运订票系统](flight-booking-system/) | C++、Win32 API、ODBC、SQL Server | 包含航班查询、订票、订单管理、候补队列和管理员后台的桌面端课程设计。 |
| [贪吃蛇游戏](Hungrysnake-game/) | C++、EasyX、Windows API | 支持多难度、多类型食物、障碍物、得分和重新开始功能的桌面小游戏。 |
| [随机菜谱生成器](random-menu-generator/) | Python、Flask、DeepSeek API | 支持菜谱浏览、随机推荐、筛选、用户上传和 AI 菜谱生成的 Web 应用。 |
| [天气查询管理系统](weather-query-system/) | Java 17、Spring Boot、Thymeleaf、SQL Server | 支持天气查询、城市对比、天气排行、用户登录和默认城市管理的 Web 应用。 |
| [答案之书](answer-book/) | Python、Tkinter、Pygame | 带抽签动画、粒子特效、烟花和电子木鱼效果的互动桌面程序。 |

## 使用说明

每个项目都包含独立的 `README.md`，说明其运行环境、依赖、配置和启动步骤。部分项目依赖本地数据库或第三方 API；可以先阅读对应项目的说明文件，并使用自己的测试数据、数据库账号和 API Key。
